# 社交媒体平台图片尺寸参考

> 设计配图时根据目标平台选择对应尺寸，关键内容放在安全区域内。

## 微信公众号

| 用途 | 推荐尺寸（px） | 宽高比 | 文件限制 | 安全区域说明 |
|------|---------------|--------|---------|-------------|
| 头条封面（大图） | 900 x 383 | 2.35:1 | ≤ 10MB | 左右各约 50px 可能被裁切；底部约 60px 被标题遮挡 |
| 次条封面（小图） | 200 x 200 | 1:1 | ≤ 10MB | 四周留 10px 安全边距 |
| 正文插图 | 宽 900px，高度不限 | 不限（常用 16:9 或 3:4） | ≤ 10MB | 手机端实际显示宽约 677px |
| 二维码名片 | 600 x 600 | 1:1 | — | 二维码周围留白至少 20px |

## 通用设计建议

1. 关键文字和主体内容放在画面中心 60-70% 区域，避开四周遮挡区
2. 竖版内容（3:4 或 9:16）在移动端信息流中占据更大面积
3. 照片类用 JPG，文字/图形类用 PNG
4. 生图时在 prompt 中指定具体像素尺寸或宽高比
